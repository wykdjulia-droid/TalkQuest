# Talk Quest

A cosy English classroom game for Japanese junior and senior high school classes.

- **Teacher (board):** open the page, choose *I'm the teacher*, create a class space and share the code.
- **Students (iPads):** open the same page, choose *I'm a student*, make a character and join with the code.

Everything is shared live through Firebase Realtime Database (config at the top of `index.html`).
If Firebase can't be reached, the game still runs on a single device.
